## Carlos Tapia

AI Architect · Multi-agent systems, in Santiago, Chile. Thirteen years on banking, telecom and public-sector systems.
On my own time I run AI coding agents on real code and measure what happens: what they cost, how
much of their code survives, where they get out of a sandbox. The notes are at
[carlostapia.cl](https://carlostapia.cl).

**Tools**

- [seisin](https://github.com/carlostapiacl/seisin): gives each agent its own folders and keys, enforced by the OS. MIT, on npm.
- [tartaros](https://github.com/carlostapiacl/tartaros): a local sandbox for coding agents, in Rust. Apache-2.0.
- [keyreeve](https://github.com/carlostapiacl/keyreeve): rotates API keys on your own machine, with recipes the community writes for each provider. Early, MIT.

**Measurements**

- [sandbox-conformance](https://carlostapiacl.github.io/sandbox-conformance/): runs the tests other sandboxes wrote for themselves against every sandbox, with the results by date.
- [denial-detours](https://github.com/carlostapiacl/denial-detours): what an agent does when it is denied a write to another role's file. Exploratory, every trial kept.
